📖 智能单词本 · 使用说明

一、这个软件想解决什么

不是把单词塞进一个更大的列表，而是帮你建立一条从“画面/感觉”到“词根演变”，再到“近义辨析”和“真实语境”的理解链。

核心感觉词根演变义项拆分近义辨析文化语境义项级 SRS

今天该复习哪个义项，由算法帮你排；你只需要每天打开「今日」，完成当天的一小段。

二、每天怎么用

  1. 导入或新建词库；
  2. 打开「今日」，按队列复习；
  3. 在「复习中心」选择某个模式专项突破；
  4. 在「统计」看进度，在「备份」定期备份；
  5. 遇到不熟或想补充的词，点「✏️ 编辑」完善核心感觉、词根、文化。

三、复习模式

🎴 翻卡牌看单词想释义，适合快速过一遍。
🧭 核心回忆先给核心感觉和画面，再回忆单词。
⚖️ 近义辨析从近义组里选出最贴合语境的那个。
🌱 词根拆解按前缀/词根/后缀拼出单词。
🔗 词义链从本义到引申义，理解多义词的逻辑。
⌨️ 拼写挑战听/看中文或例句，拼出英文单词。
✍️ 创意造句一次一个单词，最后拼成一段话。

另外还有「今日复习」和「错题复习」：答错的义项进入错题本，连续答对后自动移出。

四、快捷操作

Ctrl + Z撤销最近一次数据修改
Ctrl + Y / Ctrl + Shift + Z重做
Ctrl + F 或 /聚焦搜索框
Esc清空搜索 / 关闭表单 / 关闭弹窗
← / →上一个 / 下一个单词
空格 / 回车翻卡牌；核心回忆里任意键揭示

五、词库、编辑与导入

左侧「📝 新建」打开完整编辑器；详情页「✏️ 编辑」修改当前词。编辑器支持核心感觉、词根/词缀、词源、文化彩蛋、多义项、例句、搭配和易错。

「📥 导入」支持 JSON/CSV；JSON 可以完整保留词库、词根、近义组、文化和进度。标准库建议「导入为新词库」。

左侧字母栏点击直接跳转；键盘上按字母第一次只高亮，第二次按同一个字母才跳转。这样鼠标不会误触，键盘也有确认。

六、数据安全

桌面版主存储是 SQLite，网页版是 IndexedDB。桌面版还会写 SQLite 镜像和本地备份。

「设置 → 个性化」可以改页面背景色、面板色、文字颜色、整体不透明度、面板不透明度和壁纸透明度；壁纸会存进 App 的壁纸库，可以随时切换。支持图片、GIF、MP4/WebM 动态壁纸；桌面版还可以直接读取当前 Windows 桌面壁纸。Wallpaper Engine 的 .pkg 场景格式不能直接解码，请先导出成图片、GIF 或视频。

清理浏览器数据、重装系统、换电脑前，先「导出 → JSON」备份。恢复前软件也会自动备份当前数据。

七、常见问题

为什么有的词没有词根？ 因为不确定的词根不强行拆；宁缺毋滥。

为什么核心感觉不是释义？ 核心感觉负责“想起来”，释义负责“说准确”，两者分工不同。

为什么每天只引入一个义项？ 控制认知负担，先形成稳定复习节奏。

词库太大卡怎么办？ 列表默认分批加载，滚动到底部会自动加载下一批；也可以搜索后只看结果。
