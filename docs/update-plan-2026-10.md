# 智能单词本 · 后续更新计划（2026-10-21 修订）

> 当前版本：App **0.4.32**
> 当前数据：`六级4036_完整版_v2.json`（4036 词 / 8009 义项）
> 当前状态：Windows 桌面版为主；GitHub Actions 已恢复成功发布；手机只做 Android。
> 原则：不限制用户 DIY；数据安全优先；不重写现有 HTML/JS；内容不编造。

## 0. 已经完成的基线

### 应用

- Electron 桌面版 + 单文件网页版。
- SQLite 主存储、SQLite 镜像、JSON 备份、启动自动备份。
- 9 个复习模式、义项级 SRS、今日队列、错题本、多词库。
- 完整单词编辑器：核心感觉、词根/词缀、词源、文化彩蛋、多义项。
- 导入格式 v3 + JSON Schema + AI 生成提示词。
- 内置使用说明：理念、每天流程、9 个模式、快捷键、数据安全、FAQ。
- 列表分页 / 自动加载 / 字母跳转 / 详情固定导航。
- 设置 → 个性化：
  - 页面背景色、面板色、文字颜色；
  - 自动文字颜色；
  - 整体/面板/壁纸透明度，完整 0–100%；
  - 壁纸库：图片、GIF、MP4/WebM，App 内保存、随时切换；
  - 桌面版读取 Windows 桌面壁纸；
  - 设置随改随存。
- GitHub Actions 构建失败（UTF-8 BOM）已修复；从 0.4.9 起恢复 Release。

### 数据

- 4036 标准词库完整结构版：
  - 2472 个旧详细词；
  - 1564 个 AI 富化词；
  - 每个词都有核心感觉、中英文释义、例句、中文翻译；
  - 241 个词根家族、2589 个近义组；
  - 22 个词无可靠文化彩蛋，1844 个词无可靠词根拆分，按“宁缺毋滥”留空。

## 3. 0.4.20：稳定性回归（下一步）

### 目标

在继续加功能前，先证明 4036 词库和个性化设置不会把日常使用拖慢或弄坏。

### 要做

1. **4036 实测**
   - 空库导入 4036；
   - 已有词库导入；
   - 导入为新词库；
   - 重启、搜索、滚动、详情、复习。
2. **性能**
   - 启动 < 3 秒；
   - 搜索 < 200ms；
   - 今日队列 < 500ms；
   - 列表滚动/自动加载不卡。
3. **数据安全**
   - SQLite 迁移、中断回退、备份恢复；
   - 导入/导出 4036 数据完整。
4. **壁纸库备份**
   - 壁纸目前存在本机 IndexedDB，不随词库 JSON；
   - 增加“壁纸库导出/导入”或纳入完整备份；
   - 避免换机/清数据后壁纸丢失。
5. **设置回归**
   - 新旧设置兼容；
   - 0% 透明度、自动文字色、动态壁纸边界情况。

### 验收

- 形成 `4036_压力测试报告.md`；
- 发现的问题修完或记录；
- 壁纸库可迁移。

## 4. 0.5.0：标准词库与内容质量

### 词库格式

- 标准库版本号：`2026.10.x`；
- 校验和、只读、来源/许可证；
- 升级按 `word.uid` 合并；
- 不覆盖用户笔记、掌握度、SRS 进度；
- 保留旧版本回退。

### 内容质量

- 抽检 400 词（约 10%）；
- 重点检查 1564 个 AI 富化词；
- 假词源、假文化、错译回写修正；
- 高价值词补词根；不强行补所有词；
- 22 个空文化词：有真实内容才补；
- 生成质量报告，标出剩余留空字段。

### 分发

- 不把 25MB 数据硬塞进安装包；
- 标准库作为可选包/首次导入；
- 升级单独提示；
- 支持“标准库 + 用户词库”并存。

### 验收

- 标准库升级不丢笔记/进度；
- 抽检通过；
- 有明确质量报告和回退方案。

## 5. 0.5.x：学习闭环与统计

优先级 P1：

1. **学习仪表盘**
   - 今日到期/新词/完成/连续天数；
   - 未来 7 天复习量；
   - 当前词库进度。
2. **每词库统计**
   - 词数、已学、掌握度；
   - 到期分布；
   - 最近 7 天学习量。
3. **搜索/筛选**
   - 未学、学习中、已掌握、错题、有文化彩蛋；
   - 按词根/近义组搜索。
4. **学习会话总结**
   - 本轮正确率、耗时；
   - 下一轮建议；
   - 错题一键加入复习。
5. **SRS 细节**
   - 搁置词；
   - 反复忘记提示；
   - 答题改判/撤回。

P2：

- 自定义复习顺序；
- 移动单词到另一词库；
- 导出学习报告。
