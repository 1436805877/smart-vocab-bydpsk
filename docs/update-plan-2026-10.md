# 智能单词本 · 后续更新计划（2026-10 修订）

> 当前版本：App 0.4.8；标准词库数据 `六级4036_完整版_v2.json`（4036 词 / 8009 义项）。
> 原则：Windows 优先；手机只做 Android；不重写现有 HTML/JS；数据安全优先；内容不编造。

## 0. 当前基线

### 已完成

- Electron 桌面版 + 单文件网页版。
- SQLite 主存储 + SQLite 镜像 + JSON 备份。
- 9 个复习模式、义项级 SRS、今日队列、错题本、多词库、统一导入。
- v3 导入格式、JSON Schema、AI 生成提示词、示例词库。
- 4036 词库数据：
  - 4036 词 / 8009 义项；
  - 2472 个旧详细词；
  - 1564 个 AI 富化词；

  - 241 个词根家族、2589 个近义组；
  - 22 个词没有可靠文化彩蛋，1844 个词没有可靠词根拆分（按“不编造”留空）。

### 尚未验证 / 尚未完成

- 4036 词库在桌面版的实际导入、滚动、搜索、复习压力测试。
- SQLite 迁移的完整回归、异常中断/回滚测试。
- AI 富化的 1564 个词尚未做人工抽检。
- 标准词库的版本化升级、只读保护、按 uid 合并。
- 每词库统计、学习仪表盘、学习计划。
- Android 端。
- 自动更新、代码签名、崩溃诊断。
- 云同步/账号（1.0 后再说）。

## 2. 0.4.4：4036 实测与数据安全

**目标**：先证明“4036 词 + 8009 义项”在真实桌面环境里稳定，不急着加新功能。

### 要做的

1. **4036 导入压力测试**
   - 空库导入 4036；
   - 已有词库导入 4036；
   - 导入为新词库；
   - 导入中断/重复导入/冲突覆盖。
2. **性能测试**
   - 启动 < 3 秒；
   - 搜索 < 200ms；
   - 今日队列生成 < 500ms；
   - 详情页打开 < 300ms；
   - 连续切换 100 个词不卡死。
3. **SQLite 迁移回归**
   - 从 IndexedDB 迁移 4036 词；
   - 迁移中断后回退；
   - 数量校验失败时回退；
   - 备份、恢复、镜像恢复。
4. **数据完整性检查**
   - 4036 词 ID 唯一；
   - 8009 义项 ID 唯一；
   - core.chain 的 senseId 全部有效；
   - rootFamilyId / synonymGroupIds 全部有效；
   - 导入后词库关系 4036 条。
5. **修复实测问题**
   - 只修阻塞使用的问题；
   - 不在此版本改学习模型。

### 验收

- 4036 词库可稳定导入、重启、复习、搜索；
- 迁移失败可回退，不丢数据；
- 性能达到目标或有明确优化项；
- 形成一份 `4036_压力测试报告.md`。

### 暂不做

- Android；
- 云同步；
- 新复习模式；
- 大规模 UI 改版。

## 3. 0.5.0：标准词库与内容质量

**目标**：把 4036 从“一个 JSON 文件”变成“可版本化、可升级、可校验的标准词库”。

### 3.1 标准库格式

- 词库包增加：
  - `id`：稳定标识；
  - `name`；
  - `version`：如 `2026.10.1`；
  - `schemaVersion`；
  - `wordCount`；
  - `checksum`；
  - `source` / `license`；
  - `reviewStatus`。
- 标准库只读；
- 升级按 `word.uid` 合并；
- 不覆盖用户笔记、掌握度、SRS 进度；
- 保留旧版本回退。

### 3.2 内容质量流水线

1. **自动校验**
   - 核心感觉不能是释义；
   - 中文/英文释义不能为空；
   - 例句 + 翻译成对；
   - 词根/词源 confidence 标记；
   - 引用/文化彩蛋不得无来源。
2. **人工抽检**
   - 先抽 400 词（约 10%）；
   - 重点检查 1564 个 AI 富化词；
   - 每条记录标记 `reviewStatus: draft / checked / fixed`；
   - 发现假词源、假文化、错译，回写修正。
3. **补高价值缺口**
   - 22 个空文化词：有真实内容才补；
   - 1844 个空词根词：优先补高频词/考试高频词，不强行拆；
   - AI 词的近义组：优先把高频组接入 `synonymGroups`；
   - 不为了“满字段”编内容。

### 3.3 标准库分发

- 不直接把 25MB 数据硬编码进安装包；
- 采用：
  - 内置“标准库安装包”或
  - 首次启动可选下载/导入；
- 安装包体积可控；
- 导入后只读，不随 App 更新被覆盖；
- 标准库升级单独提示。

### 验收

- 4036 标准库有版本号、校验和、质量报告；
- 升级不丢用户笔记/进度；
- 抽检 400 词通过；
- 明确剩余留空字段清单。

## 4. 0.5.x：学习闭环与统计

**目标**：让用户每天打开就知道“今天学什么、学得怎么样”。

### 优先级 P1

1. **学习仪表盘**
   - 今日到期、今日新词、已完成、连续天数；
   - 未来 7 天复习量预测；
   - 当前词库进度；
   - 薄弱词/错题入口。
2. **每词库统计**
   - 词数、已学、掌握度分布；
   - 到期分布；
   - 最近 7 天学习量。
3. **更细的 SRS 控制**
   - 每日新词上限、到期上限已有；
   - 增加“暂停/搁置词”；
   - leech（反复忘记）提示；
   - 答题后撤回/改判。
4. **搜索与筛选**
   - 按单词、中文、词根、近义组搜索；
   - 筛选：未学/学习中/已掌握/错题/有文化彩蛋；
   - 从搜索结果直接进入复习。
5. **学习会话总结**
   - 本轮答对/答错/耗时；
   - 下一轮建议；
   - 错题一键加入今日复习。

### 优先级 P2

- 自定义复习顺序；
- 词库内“移动单词到另一词库”；
- 导入前预览冲突；
- 导出学习报告（CSV/Markdown）。

### 验收

- 用户能在 10 秒内回答“今天要做什么”；
- 统计数字与 SRS 数据一致；
- 不引入新的数据表结构，只扩展现有 JSON。

## 5. 0.6.0：Android

**目标**：手机端可离线用，不做 iOS，不做云同步。

### 技术路线

- Capacitor 复用现有 HTML/JS；
- SQLite 用 Capacitor 插件存应用沙盒；
- 复用 v3 导入格式；
- 与桌面通过 JSON 导入/导出交换数据。

### 手机 UI

- 单栏详情；
- 底部导航：今日 / 词库 / 搜索 / 统计 / 设置；
- 大按钮、触控友好的复习操作；
- 复习页适配小屏；
- 不做桌面双栏压缩。

### 验收

- Android 可安装、离线复习；
- 桌面导出的 4036 词库可导入手机；
- 手机导出的进度/笔记可回桌面；
- 不出现布局挤压/无法点击。

## 10. 建议的执行顺序

### 现在先做

1. 用 4036 v2 跑一次完整导入/重启/搜索/复习；
2. 写 `4036_压力测试报告.md`；
3. 修 0.4.4 阻塞问题；
4. 再进入 0.5 标准库。

### 不要现在做

- 不要先做 Android；
- 不要先做云同步；
- 不要先加第 10 个复习模式；
- 不要把 25MB 数据硬塞进安装包。

### 判断标准

如果 4036 导入后卡、搜索慢、迁移失败，优先修性能和存储；  
如果 4036 稳定，再投入内容抽检和标准库；  
内容稳定后，再做 Android。
