## 0. 已经完成的基线

### 应用

- Electron 桌面版 + 单文件网页版。
- SQLite 主存储、SQLite 镜像、JSON 备份、启动自动备份。
- 9 个复习模式、义项级 SRS、今日队列、错题本、多词库。
- 完整单词编辑器：核心感觉、词根/词缀、词源、文化彩蛋、多义项。
- 导入格式 v3 + JSON Schema + AI 生成提示词。
- 内置使用说明：理念、每天流程、9 个模式、快捷键、数据安全、FAQ。
- 列表分页 / 自动加载 / 字母跳转 / 详情固定导航。
- 设置 → 个性化：
  - 页面背景色、面板色、文字颜色；
  - 自动文字颜色；
  - 整体/面板/壁纸透明度，完整 0–100%；
  - 壁纸库：图片、GIF、MP4/WebM，App 内保存、随时切换；
  - 桌面版读取 Windows 桌面壁纸；
  - 每张壁纸可保存一套默认外观（颜色、透明度、可见性、流畅模式），切换壁纸自动套用；
  - 设置随改随存。
- GitHub Actions 构建失败（UTF-8 BOM）已修复；从 0.4.9 起恢复 Release。

### 数据

- 4036 标准词库完整结构版：
  - 2472 个旧详细词；
  - 1564 个 AI 富化词；
  - 每个词都有核心感觉、中英文释义、例句、中文翻译；
  - 241 个词根家族、2589 个近义组；
  - 22 个词无可靠文化彩蛋，1844 个词无可靠词根拆分，按“宁缺毋滥”留空。

### 搁置：非英文路径启动

**状态：2026-10-23 起暂停，不阻塞 0.5.0。**

已知：

- 启动日志能走到 `window created` 和 `did-finish-load OK`；
- 之后出现 `mirror save failed ... readonly database`；
- 最终 `window-all-closed`，退出码 `-2147483645`；
- 兼容启动器在用户环境没有正常启动，原因尚未锁定。

已尝试：

- 工作目录/sessionData 切到 ASCII 的 `%APPDATA%\smart-vocab`；
- 只读镜像自动重建；
- 8.3 短路径启动；
- ASCII 目录联接启动；
- 英文文件名启动器。

暂不继续的原因：

- 缺少可稳定复现的窗口级现象和崩溃堆栈；
- 当前继续盲改启动器收益低，容易引入新问题；
- 0.5.0 内容质量更优先。

用户侧临时方案：

1. 解压到纯英文路径，例如 `C:\SmartVocab`；
2. 或使用安装版 `SmartVocab-0.4.34-x64.exe`；
3. 启动失败时保留 `startup.log`，等以后重开此问题。

重开条件：

- 拿到安装版/英文路径下的成功或失败日志；
- 能确认是 Electron 主体、renderer、SQLite 还是启动器问题；
- 再决定做独立 launcher exe 或换打包方式。

## 4. 0.5.0：标准词库与内容质量

### 词库格式

- 标准库版本号：`2026.10.1`（`data-cet6.manifest.json`）；
- gzip SHA-256、词数/义项数、来源/许可证；
- 只读词库，与用户词库并存；
- 已有 4036 词时不再自动覆盖，用户笔记、掌握度、SRS 进度保持不变；
- 升级合并与旧版本回退：**尚未实现**。后续合并需要先为词/义项建立稳定键（当前数据没有 `uid`，不能按 `word.uid` 合并）；在实现之前，0.5.4 只做版本识别、完整性校验和损坏拒绝导入。

### 内容质量

- 抽检 400 词（约 10%）；
- 重点检查 1564 个 AI 富化词；
- 假词源、假文化、错译回写修正；
- 高价值词补词根；不强行补所有词；
- 22 个空文化词：有真实内容才补；
- 生成质量报告，标出剩余留空字段。

### 分发（0.5.0 实际做法）

- 25MB JSON 压缩为约 5MB 的 `data-cet6.json.gz` 随安装包分发；
- 首次启动、空库或仅 6 个演示词时由主进程写入 SQLite；
- 已有词库不覆盖；用户清空后可在空状态手动恢复；
- 标准库带只读词库，与用户词库并存。

### 验收

- 全新安装无需导入即可看到 4036 词；
- 已有用户的笔记/掌握度/SRS 进度不被覆盖；
- 空库可恢复内置词库；
- 抽检与质量报告按 0.5.x 继续推进。

### 4.1 0.5.4：标准库版本化（已完成）

- `data-cet6.manifest.json` 记录 `libraryVersion 2026.10.1`、schema、4036 词 / 8009 义项、来源、许可证和 gzip SHA-256；
- `lib/builtin-library.js` 导入前校验清单和文件哈希，失败时返回错误且不执行 `dbImportAll`；
- marker 记录 `libraryVersion` 和 `sha256`，设置页显示清单版本、规模、来源、本次数据标记和校验结果；
- `npm run test:builtin` 覆盖首次导入、重复启动、损坏拒绝、清空后不自动灌入、手动恢复；
- 打包白名单和便携版复制清单同步加入 manifest。

验收：`npm run test:builtin` 通过；设置页能看到 `2026.10.1` 和校验通过；篡改 gzip 后不写入数据库。

## 5. 0.5.x：学习闭环与统计

优先级 P1：

1. **学习仪表盘**
   - 今日到期/新词/完成/连续天数；
   - 未来 7 天复习量；
   - 当前词库进度。
2. **每词库统计**
   - 词数、已学、掌握度；
   - 到期分布；
   - 最近 7 天学习量。
3. **搜索/筛选**
   - 未学、学习中、已掌握、错题、有文化彩蛋；
   - 按词根/近义组搜索。
4. **学习会话总结**
   - 本轮正确率、耗时；
   - 下一轮建议；
   - 错题一键加入复习。
5. **SRS 细节**
   - 搁置词；
   - 反复忘记提示；
   - 答题改判/撤回。

P2：

- 自定义复习顺序；
- 移动单词到另一词库；
- 导出学习报告。
