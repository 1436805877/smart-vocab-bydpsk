# 智能单词本 未来开发路线图

> 更新：2026-10-19（0.1.5 fix-1）
> 目标：保留「核心感觉 + 词根演变 + 近义辨析」的学习方式，先做 Windows，再一步到位做手机；不把数据锁死在浏览器里。

## 1. 当前状态

已经完成：

- 网页版 + Windows Electron 桌面版；
- 0.1.5 fix-1，GitHub Actions 可稳定构建 NSIS 安装包和便携版；
- 9 个复习模式：翻卡牌、核心回忆、近义辨析、词根拆解、词义链、拼写、射手、消消乐、创意造句；
- v2 数据字段：`core`、`senses`、`morphology`、`etymology`、`coreLink`；
- 共享库已入库：`rootFamilies`、`synonymGroups`、`confusionPairs`；
- 导入/导出保留词根、近义、易混数据；
- 义项随机出题，词义链选项包含本词全部义项；
- 数据仍在 IndexedDB（`SmartVocabDB_v9`），桌面版数据目录是 `%APPDATA%\smart-vocab`。

还没做：

- 义项级 SRS、每日队列、错题本；
- SQLite、多词库（标准库/用户库）、自动备份；
- 4036 标准词库内置（等内容优化后再做）；
- 手机端、自动更新、代码签名。

## 2. 开发原则

1. **学习效果优先**：先做“每天该复习什么”，再做外观和平台。
2. **数据安全优先**：任何迁移前先备份；宁可功能少，不可丢词。
3. **Windows 优先**：先把桌面版打磨到每天可用，再上手机。
4. **4036 词库不提前内置**：先把词库内容质量做好，再进安装包。
5. **一套 UI，多种壳**：网页、Electron、Capacitor 共用同一套核心界面。
6. **不重写**：继续用现有 HTML/JS，逐步拆模块；不为了“技术先进”换框架。
7. **一个阶段只解决一个核心问题**：避免功能很多但都不能用。

## 3. 总路线

| 阶段 | 核心目标 | 用户能感知的结果 |
|---|---|---|
| **0.2** | 学习闭环 | 每天打开就知道复习哪些义项；错题自动收集 |
| **0.3** | 数据层与词库 | 可以建多个词库；数据有 SQLite/备份；不再怕清缓存 |
| **0.4** | 内容与标准库 | 你的优化词库可以打包/升级/合并，不覆盖学习记录 |
| **0.5** | 手机端 | Android 一步到位；桌面/手机都能用 |
| **1.0** | 稳定版 | 自动更新、签名、备份恢复、迁移验证、文档齐全 |
| 以后 | 云同步/AI | 多设备同步、AI 辅助整理；不阻塞 1.0 |

## 4. 0.2 学习闭环（当前优先）

### 0.2.1 义项级 SRS

要解决的问题：现在只记“这个单词复习过”，不记“哪个义项会/不会”。

数据：

- 新增 `progress` 存储，键为 `wordId:senseId`；
- 每个义项记录：`dueAt`、`interval`、`ease`、`reps`、`lapses`、`lastGrade`、`wrongCount`、`lastReviewedAt`；
- 单词级掌握度保留，作为汇总展示。

算法：

- 先用简单的间隔重复（类似 Leitner / SM-2 lite），不做复杂 FSRS；
- 三档反馈：忘记 / 模糊 / 记得；
- 间隔建议：0、1、3、7、14、30 天，按表现调整；
- 答错回到短间隔，并进入错题本。

出题：

- 翻卡牌、拼写、射手、消消乐、词义链传入 `senseId`，按义项记录；
- 核心回忆、词根拆解、近义辨析是词级模式，更新单词汇总，不强行拆义项。

验收：

- 同一个词的不同义项可以有不同的下次复习时间；
- 答题后刷新/重启，进度不丢；
- 统计页能看到“已到期义项数”。

### 0.2.2 每日队列 + 错题本

每日队列：

- 打开复习页先看到「今日任务」；
- 默认：最多 20 个新义项 + 最多 60 个到期义项，可调；
- 到期优先，其次新词；同一单词的多个义项尽量分散；
- 完成一组后给小结：复习数、正确率、错题数。

错题本：

- 答错自动加入；
- 支持“只复习错题”；
- 连续答对 2 次自动移出，也可以手动移除；
- 错题按词/义项记录，不按复习模式重复收集。

验收：

- 今天该复习什么，不需要自己想；
- 错题能单独清掉；
- 队列完成后有明确反馈。

### 0.2.3 自动备份 + 恢复

- 桌面版启动/退出时自动导出 JSON 到 `%APPDATA%\smart-vocab\backups\`；
- 保留最近 7 份；
- 数据库升级前强制备份一次；
- 增加「备份与恢复」页面：列出备份、预览词数、恢复前确认；
- 网页版不能自动写磁盘，保留导出提醒。

验收：

- 误删/迁移失败可以从最近备份恢复；
- 备份文件能重新导入。

### 0.2 完成标准

- 每天可以只用「今日任务」完成复习；
- 义项进度和错题能跨重启保存；
- 有一份可恢复的备份；
- 现有 9 个模式不退化。

## 5. 0.3 数据层与词库

### 5.1 DataStore 抽象

- 定义 `DataStore` 接口：words、senses、extras、progress、decks、backups；
- 实现：
  - `IndexedDBStore`：网页版/开发预览；
  - `SQLiteStore`：Windows/手机；
  - `MemoryStore`：自动测试。
- 业务代码只调用接口，不直接碰 IndexedDB/SQLite。

### 5.2 SQLite

- Windows 主进程用 SQLite 存 `%APPDATA%\smart-vocab\wordbook.db`；
- 渲染进程通过 IPC 调用；
- 迁移时保留 IndexedDB 作为回退，不直接删除旧数据；
- 大数据量（4000+ 词、1 万+ 义项）下列表/搜索要流畅。

### 5.3 多词库

- `decks`：标准库、用户词库、导入包；
- `deck_words`：多对多；
- 同一个词可以在多个词库，学习进度按词/义项共享；
- 标准库只读，升级按 `uid` 合并，不覆盖用户笔记和进度；
- 用户可启用/停用/删除词库；
- 复习队列可选：当前词库 / 全部启用 / 只看错题。

### 5.4 数据安全

- 所有词/义项/词库加 `uid`、`updatedAt`、`deletedAt`；
- 迁移脚本可重复执行；
- 每次 schema 升级先备份；
- 导入冲突按 `uid`/word 合并，保留用户数据。

验收：

- 标准库示例包可以导入、启停、升级；
- 卸载重装后学习记录可恢复；
- 4000 词下搜索和复习队列不卡。

## 6. 0.4 内容与标准库

前提：你对 4036 词的内容优化完成，或至少给出可用的定稿。

- 把转换脚本升级为“内容管线”：
  - 校验核心感觉是否像释义；
  - 校验义项、词根、近义组、例句是否完整；
  - 生成质量报告：缺字段、疑似错误、重复词；
- 标准库打包为只读 deck，带 `version`；
- 支持导入第三方词库包，保留 `source`；
- 可选 AI 辅助补全，但必须人工抽检，不自动发布；
- 版权/来源确认后再内置。

验收：

- 标准库可升级，学习记录不丢；
- 内容问题能定位到具体词/字段；
- 用户词库和标准库可以共存。

## 7. 0.5 手机端

- Capacitor 复用现有 UI；
- Android 优先，iOS 后做（需要 Mac + Apple 开发者账号）；
- SQLite 用 Capacitor 插件存应用沙盒；
- 手机 UI 单独适配：
  - 底部导航；
  - 单栏详情；
  - 大按钮、触控友好的复习操作；
- 跨设备先走“导出/导入”，不做云同步；
- 手机端不内置 4036 内容，除非安装包体积和版权都确认。

验收：

- Android 安装包可安装、可离线复习；
- 桌面导出的 JSON 能导入手机，反之亦然；
- 手机端不出现桌面双栏挤压。

## 8. 1.0 稳定版

- 数据迁移经过多个版本验证；
- 自动备份/恢复可用；
- 自动更新（electron-updater + GitHub Releases）；
- 代码签名（可选，未签名会有 SmartScreen 提示）；
- 崩溃日志/启动诊断可收集；
- 隐私说明、许可证、使用文档齐全；
- 性能：4000+ 词、1 万+ 义项可用；
- 此时再考虑云同步、账号、AI 生成。

## 9. 暂不做

- 4036 标准词库内置（等内容定稿）；
- 云同步/账号体系（先本地 + 备份）；
- macOS/Linux 桌面版；
- PWA 正式发布；
- Flutter/React Native 重写；
- 为每个新题型改数据库表结构（内容字段用 JSON）。

## 10. 建议的默认选择

如果你没有特别偏好，我建议：

1. **SRS**：先用简单间隔重复，不做 FSRS；
2. **每日任务**：20 个新义项 + 最多 60 个到期义项，可调；
3. **错题本**：答错自动收集，连续答对 2 次移出；
4. **备份**：启动/退出自动备份，保留 7 份；
5. **手机**：Android 优先，iOS 后做；
6. **界面**：保留现在这套，不重新设计。
