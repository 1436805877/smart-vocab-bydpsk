# 智能单词本 开发路线图

> 更新：2026-10-19（0.4.0）
> 目标：保留「核心感觉 + 词根演变 + 近义辨析」的学习方式；Windows 优先，手机只做 Android；4036 词库等内容优化后再内置。

---

## 1. 当前状态

### 已完成

**产品形态**

- 网页版：单文件 `index.html`。
- Windows 桌面版：Electron，NSIS 安装包 + 便携版。
- 数据目录：`%APPDATA%\smart-vocab`。
- 备份目录：`%APPDATA%\smart-vocab\backups`。
- SQLite 主存储：`%APPDATA%\smart-vocab\wordbook.db`（桌面版）。
- SQLite 镜像：`%APPDATA%\smart-vocab\wordbook-mirror.db`（额外兜底）。

**学习功能**

- 9 个复习模式：
  - 翻卡牌
  - 核心回忆
  - 近义辨析
  - 词根拆解
  - 词义链 / 义项选择
  - 拼写挑战
  - 单词射手
  - 消消乐
  - 创意造句
- 义项级 SRS：
  - 每个义项独立记录 `dueAt / interval / ease / reps / lapses`；
  - 忘记 / 模糊 / 记得三档；
  - 1、3、7、14、30 天步进。
- 今日队列：
  - 到期优先；
  - 新词上限、到期上限可调；
  - 每个新词每天只引入一个义项。
- 错题本：
  - 答错自动进入；
  - 连续答对 2 次移出；
  - 支持只复习错题。
- 设置：
  - 答完一题是否自动下一题；
  - 自动切换延迟 0.8–3 秒；
  - 关闭后显示「下一题」按钮。
- 交互：
  - `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`；
  - 核心回忆、今日复习支持点击任意区域/按任意键揭示；
  - 翻卡牌空格/回车翻转。

**数据与词库**

- v2 字段：`core`、`senses`、`morphology`、`etymology`、`coreLink`。
- 共享库：`rootFamilies`、`synonymGroups`、`confusionPairs`。
- 多词库：
  - `decks` / `deckWords`；
  - 默认「我的词库」；
  - 新建/切换/重命名/删除用户词库；
  - 只读标准词库框架；
  - 单词与词库多对多；
  - 学习进度按词/义项共享。
- 统一导入：
  - 普通导入按 JSON 里的 `decks` / `deckWords` 导入；
  - 导入为新词库；
  - 导入到已有词库；
  - 多文件合并。
- 备份/恢复：
  - 手动备份；
  - 启动超过 12 小时自动备份；
  - 内部保留 7 份；
  - 桌面本地 JSON 保留 7 份；
  - 恢复前自动安全备份；
  - 可从 JSON 文件恢复。
- SQLite 镜像：
  - 桌面主进程用 `node:sqlite` 写快照；
  - 每次保存后更新；
  - 备份页可查看/恢复镜像；
  - **目前仍是镜像，不是主存储。**

### 尚未完成

- SQLite 主存储与迁移已落地；迁移验证和 4000 词压力测试仍待补。
- `DataStore` 抽象尚未落地。
- 4036 标准词库尚未内置。
- 词库“把已有单词移动到另一个词库”的界面。
- 每词库独立统计。
- 自动更新、代码签名。
- Android 端。
- 云同步/账号体系。

### 测试状态

- 0.3.4 已写好完整测试清单：`测试清单.md`。
- 你目前还没有系统测试 0.3.x / 0.4.0。
- 因此下一步开发应优先做**低风险、可回退**的数据层，而不是同时改学习模型和存储。

---

## 2. 开发原则

1. **学习效果优先**：先保证每天知道复习什么。
2. **数据安全优先**：迁移前必须自动备份；宁可功能少，不可丢词。
3. **Windows 优先**：先把桌面版打磨到每天可用。
4. **4036 不提前内置**：等词库内容定稿，再进安装包。
5. **一套 UI，多种壳**：网页、Electron、Android 共用核心界面。
6. **不重写**：继续用现有 HTML/JS，逐步拆模块。
7. **一个阶段只解决一个核心问题**。
8. **不破坏旧数据**：每次 schema 升级先备份，保留回退路径。
9. **手机只做 Android，不做 iOS。**

---

## 3. 总路线（修订版）

| 阶段 | 核心目标 | 用户能感知的结果 |
|---|---|---|
| **0.3.x** | 词库与交互完善 | 多词库、统一导入、快捷键、设置、SQLite 镜像 |
| **0.4** | 数据层 | SQLite 已做主存储；迁移/回退已接入；待压力测试 |
| **0.5** | 内容与标准库 | 你的优化词库可打包/升级/合并；4036 按内容进度内置 |
| **0.6** | Android | 手机端一步到位；桌面/手机可互相导入导出 |
| **1.0** | 稳定版 | 自动更新、签名、备份恢复、迁移验证、文档齐全 |
| 以后 | 云同步/AI | 多设备同步、AI 辅助整理；不阻塞 1.0 |

> 原计划把 SQLite 放在 0.3；实际 0.3 先完成了词库和交互，所以数据层顺延到 0.4。

## 4. 0.4 数据层（已落地，待验证）

### 4.1 DataStore 抽象

- 定义统一接口：
  - `words`
  - `senses`
  - `extras`
  - `progress`
  - `decks`
  - `deckWords`
  - `backups`
- 实现：
  - `IndexedDBStore`：网页版 / 开发预览；
  - `SQLiteStore`：Windows / 未来 Android；
  - `MemoryStore`：自动测试。
- 业务代码只调用接口，不直接碰 IndexedDB/SQLite。

### 4.2 SQLite 主存储

- 桌面版数据库：`%APPDATA%\smart-vocab\wordbook.db`。
- 表建议：
  - `words`：id、uid、json、updated_at、deleted_at；
  - `senses`：id、uid、word_id、json；
  - `progress`：key、word_id、sense_id、json；
  - `decks`：id、uid、json；
  - `deck_words`：deck_id、word_id；
  - `extras`：key、json；
  - `backups`：id、created_at、json；
  - `meta`：schema_version、last_migration。
- 内容字段先用 JSON 存，避免每加一个字段就改表。
- 关键查询（列表、搜索、到期义项）必须走索引或内存索引。

### 4.3 迁移流程

1. 检测旧 IndexedDB 数据。
2. 迁移前自动备份：
   - JSON 备份；
   - SQLite 镜像。
3. 逐项写入 SQLite，校验数量：
   - 单词数；
   - 义项数；
   - 进度数；
   - 词库数。
4. 校验通过后切换为 SQLite 主存储。
5. 保留 IndexedDB 只读回退：
   - 迁移失败/数量不一致时回退；
   - 用户可手动选择“从旧数据恢复”。
6. 记录迁移日志，失败可诊断。

### 4.4 备份与回滚

- 每次 schema 升级前强制备份。
- SQLite 文件 + JSON 双备份。
- 恢复前自动备份当前数据。
- 支持“从 SQLite 镜像恢复”作为最后兜底。

### 4.5 性能目标

- 4000 词、1 万义项：
  - 启动 < 3 秒；
  - 搜索 < 200ms；
  - 今日队列生成 < 500ms；
  - 保存不阻塞输入。
- 如不达标，先做分页/虚拟列表/索引优化，再上内容。

### 4.6 验收

- 迁移 4000 词合成数据成功；
- 迁移中断后可恢复；
- 学习进度、错题、词库、备份全部保留；
- IndexedDB 数据不被删除；
- 桌面版重启后从 SQLite 读取；
- 网页版仍用 IndexedDB。

## 5. 0.5 内容与标准库

前提：你对 4036 词库内容优化完成，或给出可用定稿。

- 词库包格式：
  `{ id, name, version, description, words, rootFamilies, synonymGroups, decks }`
- 标准库：
  - 只读；
  - 带 `version`；
  - 升级按 `uid` 合并；
  - 不覆盖用户笔记和进度。
- 用户词库：
  - 普通导入；
  - 导入为新词库；
  - 导入到已有词库；
  - 后续补“移动单词到词库”。
- 内容管线：
  - 校验核心感觉是否像释义；
  - 校验义项/词根/近义组/例句完整性；
  - 生成质量报告；
  - 可选 AI 辅助补全，但必须人工抽检。
- 4036 标准库是否内置、是否随安装包、是否在线下载，等内容定稿后决定。

### 验收

- 标准库升级不丢学习记录；
- 用户词库可启停；
- 内容问题能定位到具体词/字段。

## 6. 0.6 Android

- Capacitor 复用现有 UI。
- 只做 Android，不做 iOS。
- SQLite 用 Capacitor 插件存应用沙盒。
- 手机 UI 单独适配：
  - 底部导航；
  - 单栏详情；
  - 大按钮、触控友好的复习操作。
- 跨设备先走“导出/导入”，不做云同步。
- Android 安装包通过 GitHub Actions 或本地构建。

### 验收

- Android 可安装、离线复习；
- 桌面导出的 JSON 能导入手机，反之亦然；
- 手机不出现桌面双栏挤压。
